Trackus adds canonical tracker metadata, public Firebase timestamp types, and typed stable-entry requests for personal progress tracking. Its Angular support moves to the verified Angular 22 line; the former Angular 21 peer graph cannot resolve with the supported shared packages. Existing published versions remain immutable.

Commitius consumes the compatible published template contract without changing its public exports. Assetus widens its Angular peer range to include Angular 22. The qualified consumer uses Angular 22; this does not assert whole-graph Angular 21 support.
