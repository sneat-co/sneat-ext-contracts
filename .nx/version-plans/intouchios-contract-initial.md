First release of the InTouchKeeper (`intouchios`) extension contract. It is seeded from `sneat-ext-contract-template` with the starter list DTOs, contexts and the `INTOUCHIOS_SERVICE` token that the scaffolded `sneat-co/intouchios` implementation consumes as `^0.1.0`. The relationship-memory domain types (contacts, interactions, memories, follow-ups) come in later releases.
