# Work contract

`@sneat/extension-work-contract` is the public, implementation-free API
for Work. It exposes Work DTOs, service interfaces, and Angular DI
tokens. Hosts provide concrete implementations from a private Work runtime;
consumers must not import implementation classes from this package.
