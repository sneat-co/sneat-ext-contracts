# Schoolus contract

`@sneat/extension-schoolus-contract` is the public, implementation-free API
for Schoolus. It exposes Schoolus DTOs, service interfaces, and Angular DI
tokens. Hosts provide concrete implementations from a private Schoolus runtime;
consumers must not import implementation classes from this package.
