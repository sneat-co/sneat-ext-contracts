# Trackus contract

`@sneat/extension-trackus-contract` is the public, implementation-free API
for Trackus. It exposes Trackus DTOs, service interfaces, and Angular DI
tokens. Hosts provide concrete implementations from a private Trackus runtime;
consumers must not import implementation classes from this package.
